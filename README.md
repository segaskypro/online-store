# Проект "Онлайн-магазин"

## Описание
Реализация классов для управления товарами и категориями интернет-магазина.

## Функционал

### Основные классы
- **Product** - базовый класс для представления товара
- **Category** - класс для представления категории товаров
- **Smartphone** - класс для смартфонов (наследник Product)
- **LawnGrass** - класс для газонной травы (наследник Product)

### Автоматический подсчёт
- Количество категорий (`Category.category_count`)
- Количество товаров (`Category.product_count`)


#### Абстрактный класс BaseProduct
Создан абстрактный базовый класс `BaseProduct`, который определяет обязательный интерфейс для всех продуктов:
- `__init__` - конструктор с базовыми параметрами
- `__str__` - строковое представление продукта
- `__add__` - сложение продуктов (подсчет общей стоимости)
- `price` - геттер и сеттер для цены

Класс `Product` теперь наследуется от `BaseProduct`, а `Smartphone` и `LawnGrass` - от `Product`.

#### Класс-миксин ProductReprMixin
Добавлен класс-миксин `ProductReprMixin`, который автоматически выводит информацию о создании любого продукта:


#### Классы-наследники
- **Smartphone** - дополнительные атрибуты:
  - `efficiency` (производительность)
  - `model` (модель)
  - `memory` (объем памяти)
  - `color` (цвет)

- **LawnGrass** - дополнительные атрибуты:
  - `country` (страна-производитель)
  - `germination_period` (срок прорастания)
  - `color` (цвет)

#### Ограничения и защита
- **Сложение товаров**: можно складывать только товары одного класса (Product, Smartphone или LawnGrass)
- **Добавление в категорию**: защита от добавления объектов, не являющихся продуктами

## Установка и запуск

```bash
# Клонирование репозитория
git clone <url-репозитория>
cd online_store

# Установка зависимостей
pip install pytest pytest-cov flake8

# Запуск программы
python main.py

# Запуск тестов с подробным выводом
pytest tests/test_main.py -v

# Проверка покрытия
pytest --cov=main tests/

# Проверка стиля кода
flake8 main.py
```
