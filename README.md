# Проект "Онлайн-магазин"

## Описание
Реализация классов для управления товарами и категориями интернет-магазина.

## Функционал
- Класс `Product` для представления товара
- Класс `Category` для представления категории товаров
- Автоматический подсчёт количества категорий и товаров
- Написаны тесты с покрытием >75%

## Критерии выполнения
- [x] Созданы классы Product и Category
- [x] Определены атрибуты классов
- [x] Добавлены атрибуты класса для подсчёта
- [x] Написаны тесты
- [x] Покрытие тестами >75%
- [x] Не более 5 ошибок flake8
